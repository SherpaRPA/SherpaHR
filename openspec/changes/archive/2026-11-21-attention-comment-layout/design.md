# Design

## Context

В `frontend/src/app.html` блок `.attention-excerpt` выводится только при наличии `row.latest_comment`. Он уже получает автора, дату создания и фрагмент; для даты шаблон явно указывает UTC. У блока есть `white-space: pre-wrap` и `overflow-wrap: anywhere`.

## Goals / Non-Goals

**Goals:** держать заголовок, дату и автора в одной строке, перенести текст комментария на следующую строку с небольшим одинарным интервалом и сохранить курсив только для текста.

**Non-Goals:** вводить отдельный компонент, менять контракт `GET /api/attention`, формат обсуждения в карточке или оформление остальной очереди.

## Decisions

- Оставить условие показа и контейнер `.attention-excerpt`. В первой строке вывести заголовок, `DatePipe` с форматом `d.MM.yyyy HH:mm` и часовым поясом `UTC`, затем автора; разделять элементы символом `·`. Форматирование даты в API не требуется.
- Задать явную границу строки перед текстом комментария, чтобы он начинался ниже метаданных и на широком экране. Курсив оставить только на тексте комментария.
- Создать компактный интервал между строкой метаданных и текстом одним способом. Не добавлять одновременно margin/padding и пустую строку/дополнительный `line-height`, чтобы интервал не удваивался. Сначала проверить текущие стили и исключить уже существующие соседние отступы.

## Risks / Trade-offs

- [Лишние пробелы или пустая строка из-за `pre-wrap`] → проверить отрисованную разметку, в том числе с многострочным фрагментом; не полагаться на отступы в исходнике для разделения строк.
- [На узкой ширине длинный автор или фрагмент не помещается] → сохранить обычный перенос текста внутри обеих частей и проверить отсутствие горизонтального переполнения.
