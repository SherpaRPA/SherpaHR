# Proposal

## Why

В очереди «Требует внимания» виден фрагмент последнего комментария, но без открытия карточки нельзя понять, насколько он свежий.

## What Changes

- Показывать дату и время создания последнего комментария после автора, перед текстом фрагмента: «Последний комментарий · Анна · руководитель: 2.11.2026 13:16 UTC · Новый комментарий».
- Сохранить курсив только у текста фрагмента. Для задач без комментариев не показывать этот блок.
- Не менять правила отбора и сортировки задач, выбор последнего комментария и отображение полной переписки.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `project-attention`: показ времени создания последнего комментария в обзоре.

## Impact

`GET /api/attention` добавляет `created_at` в непустой объект `latest_comment`. Фронтенд обновляет тип ответа и шаблон обзора; проверка API дополняется. Миграции и новые зависимости не нужны.
