# Proposal

## Why

Пояснение в разделе «Требует внимания» визуально слишком близко к списку задач, из-за чего хуже различаются описание обзора и его содержимое. Небольшой вертикальный интервал сделает структуру страницы яснее без изменения текста и поведения.

## What Changes

- Добавить визуальный отступ между пояснением обзора и очередью задач.
- Сохранить текущее содержание пояснения, список, состояния загрузки и пустого результата без изменений.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Изменение касается только визуального представления и не меняет требования к поведению обзора.

## Impact

- `frontend/src/styles.css`: стили области заголовка/очереди обзора.
- `frontend/src/app.html`: текущая структура страницы служит точкой привязки; изменение разметки не предполагается, если имеющиеся контейнеры позволяют задать отступ стилями.
