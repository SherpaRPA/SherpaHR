# Spec Delta

## ADDED Requirements

### Requirement: Визуальное выделение названий задач в очереди
Интерфейс SHALL отображать названия задач в очереди «Требует внимания» полужирным шрифтом (`600`) размером `14px`, на `1px` больше, чем в таблице проекта. Изменение MUST сохранять прежнее оформление номера `#ID` и названий задач в таблице проекта.

#### Scenario: Название выделено в очереди
- **WHEN** руководитель открывает непустую очередь «Требует внимания»
- **THEN** название каждой задачи отображается с размером `14px` и насыщенностью `600`, а номер `#ID` сохраняет размер `11px` и насыщенность `500`.

#### Scenario: Оформление таблицы проекта не меняется
- **WHEN** пользователь открывает таблицу задач проекта
- **THEN** названия задач сохраняют размер `13px` и насыщенность `500`.
