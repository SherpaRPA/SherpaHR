# Журнал и сдача SherpaHR

Этот скил определяет только отчётность и передачу результата. Способ выполнения,
агента, модель и инструменты выбирает кандидат. Требования к продукту — в ТЗ.
Действуй в рамках поручения; подготовка файлов или ревью не запускают сдачу.

## Начало журнала

1. Прочитай `AGENTS.md` и [формат записей](references/journal.md).
2. Найди issue этой попытки в `SherpaRPA/SherpaHR`. При продолжении прочитай
   историю и используй ту же issue и PR, не создавай дубликаты.
3. Для новой попытки создай issue по `.github/ISSUE_TEMPLATE/candidate-task.md`.
   Зафиксируй логин кандидата, версию задания, форк, ветку и доступные сведения
   об агенте/модели. Опубликуй исходный пользовательский промпт.

## По ходу работы

- Каждый новый промпт и уточнение публикуй полностью до работы по нему.
- Каждое действие агента записывай отдельно: начало/конец, связанный промпт,
  действие, безопасные входные данные, результат, ошибки и изменения.
- Указывай фактическую модель и использованные инструменты. Для skills и MCP
  записывай реальное применение, если оно было; не предписывай их подключение.
- Все выполненные проверки логируй с результатом и SHA. Не выдавай отсутствие
  запуска за успешную проверку. Доступные артефакты связывай ссылками.
- Смену модели, остановку, возобновление и повтор действия тоже фиксируй.
- Сохраняй историю. Исправляй вывод новой записью со ссылкой на предыдущую.

Публикуй записи по ходу работы. Если отправка недоступна, сохраняй записи
с исходным временем и обозначай задержку; не выдавай позднюю публикацию
за своевременную. После отправки проверяй запись по ID/URL, перед повторной
отправкой исключай дубликат. Не заявляй о полноте недоступных данных.

## Сдача

Оформи PR внутри форка кандидата, итоговый отчёт и обязательный комментарий
с `@fxpw` в центральной issue по [submission.md](references/submission.md).
Запрос review в PR — дополнительный, если доступен. Проверь публикацию,
закрой свою issue как «сдано на проверку» и оставь PR открытым.

При доработке продолжай ту же issue/PR, фиксируй новые промпты и все действия,
обнови отчёт для нового SHA и снова опубликуй сдачу с `@fxpw`.
